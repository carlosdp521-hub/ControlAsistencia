# Control de Asistencia 📱

Aplicación móvil desarrollada en **Kotlin** utilizando **Android Studio** y **Jetpack Compose**.

## Descripción

Control de Asistencia permite registrar de manera sencilla la entrada y salida de una jornada laboral.

La aplicación muestra:

- Nombre del usuario.
- Fecha actual.
- Hora actual.
- Estado de la asistencia.
- Registro de entrada.
- Registro de salida.
- Historial de asistencia.
- Interfaz desarrollada con Jetpack Compose.
- Diseño basado en Material 3.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- AndroidX
- Gradle
